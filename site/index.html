01

Install

$ curl -fsSL https://hades.sh/install.sh | sh

One script, idempotent. It checks prerequisites (Docker, cloudflared, Rust), builds the binaries, puts the daemon under launchd so it survives reboots and crashes, wires a push-notification channel to your phone, and runs the doctor — it will not call the host ready until every check passes.

02

Three steps

1

Install

Run the script on the Mac that will serve. No account, no port forwarding, no YAML rituals.

# on the host curl -fsSL https://hades.sh/install.sh | sh
2

Log in

Connect the CLI to your host — same machine, or any other via hades host connect-info.

$ hades login ⚖ you have entered the underworld doctor GREEN — ready for deploys capacity 6348MB allocatable
3

Deploy

Scaffold a manifest in any project, deploy, get a public link. Deploys are idempotent — retries are always safe.

$ hades init && hades deploy hello deployed public: https://…trycloudflare.com
03

Built for real hardware

Uptime

Downtime, classified

Laptops sleep. HADES detects every downtime window and classifies it — slept / crashed / rebooted — in an uptime ledger. Your phone gets a priority push when the host returns, carrying the new links.

Power

Battery, diagnosed

Continuous telemetry feeds a degradation diagnosis: high-charge dwell, cycle burn, heat under load — including how much was HADES' own doing. Apps can opt to pause on battery.

Memory

Admission control

Memory must be declared. Overcommitting deploys are refused, and the refusal carries the full allocation ledger so you know what to shrink. Hard limits, OOM detection, restart backoff, crash-loop cutoff.

Load

Deliberate shedding

Replicas are round-robined. Floods are met with 503 + Retry-After, never collapse. Under pressure, low-priority apps pause first — critical ones are never touched.

05

For agents

0ok — parse stdout as one JSON object (--json)
2host not ready — doctor red, remedies in the report
3deploy rejected — overcommit; the error carries the ledger
4not found
5daemon unreachable
6invalid spec
7unauthorized — bad or missing token

The CLI is the entire interface — no MCP server, no SDK, no dashboard. An agent that can run a shell can operate the whole host: hades deploy --json | jq -r .app.url
